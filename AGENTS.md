# AI Search Overview Kit

Use npm. Build with `npm run build`, type-check source/tests/examples with `npm run type-check`, and run deterministic offline units with `npm test`. Live checks are explicit and never run in the default suite. Keep comments for protocol facts, constraints and public contracts. Preserve fixture provenance and distinguish real captures from synthetic layouts. No credentials, cookies, generated caches, binaries or browser profiles belong in Git or npm.
